# Python Assignment 1 – Data Structures

## 📌 About

This repository contains my **Python Assignment 1**, which focuses on basic **Data Structures – Strings and Tuples**.

I completed this assignment using **Python in Jupyter Notebook through Anaconda**.

## 📚 Topics Covered

### 1. Strings

The following string concepts are covered:

* String concatenation
* Taking input from the user
* String indexing
* String slicing
* Reversing a string
* Finding specific characters or words using slicing
* Converting strings to uppercase
* Converting strings to lowercase
* Capitalizing strings
* Counting character occurrences
* Replacing text in a string

### 2. Tuples

The following tuple concepts are covered:

* Creating tuples
* Concatenating tuples
* Repeating tuple elements
* Accessing elements using indexing
* Accessing the first three elements
* Accessing the last three elements
